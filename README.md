# Vassal Barons - Criação de Vassalos

## 🏰 Sobre o Mod

**Vassal Barons** é um mod para _Mount & Blade II: Bannerlord_ que expande o sistema de vassalagem do jogo, permitindo ao jogador criar novos vassalos de forma prática e imersiva. Tenha controle total sobre quem se tornará seu vassalo, escolha feudos, personalize clãs e integre familiares, tudo via diálogos intuitivos!

---

## ⚙️ Funcionalidades Principais

- **Ofereça vassalagem a NPCs qualificados** diretamente em diálogos.
- **Selecione o feudo** (cidade ou castelo) que será concedido ao novo vassalo.
- **Nomeie o novo clã** do vassalo com total liberdade.
- **Inclua familiares automaticamente** (cônjuge e filhos) no novo clã do vassalo.
- **Integração nativa** com o sistema de reinos e clãs do Bannerlord.

---

## 📝 Instalação

1. **Extraia** o arquivo `.zip` baixado do mod.
2. **Copie** a pasta `VassalBarons` para o diretório:
   ```
   Steam\steamapps\common\Mount & Blade II Bannerlord\Modules
   ```
3. **Ative** o mod no launcher do Bannerlord, acessando o menu `Mods`.

---

## 🔄 Compatibilidade

- **Versão do jogo:** e1.2.12+ (testado até e1.2.12)
- **Compatível com:**
  - Mods que **não alteram diálogos de lordes**
  - Mods de sistemas de reino (_Kingdom Destruction_, _Diplomacy_, etc.)
- **Incompatível com:**
  - Mods que **substituem** o diálogo base `lord_talk_speak_diplomacy_2`
